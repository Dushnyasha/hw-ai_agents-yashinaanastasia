# ДЗ № 1 — Мини-трекер учебных задач

**Курс:** «Создание ИИ-агентов с нуля» (ФКН НИУ ВШЭ)  
**Вариант:** A — разработка в двух независимых чатах  
**Модель ИИ:** **GPT-6**, ChatGPT (веб-интерфейс); одна и та же модель для обеих попыток

## О проекте

Мини-трекер позволяет вести учебные задачи на неделю: добавлять и удалять задачи, менять отметку «готово», фильтровать список («Все», «Активные», «Готовые»), смотреть суммарные часы и процент выполнения. Прогресс рассчитывается **по часам**, а не по количеству задач.

Сравниваются два подхода к разработке одной задачи:

- **`tracker-v1.html`** — создание по короткому прямому запросу к ИИ, без предварительной спецификации.
- **`tracker-v2.html`** — сначала четыре документа спецификации в формате OpenSpec, затем отдельный запрос на создание кода по этим документам.

Вариант A выполнялся в веб-чате: **OpenSpec CLI и валидатор не запускались**.

## Как запустить

1. Откройте репозиторий на GitHub.
2. Нажмите на `tracker-v1.html` или `tracker-v2.html` и скачайте файл через **Download raw file** (либо скачайте весь репозиторий через **Code → Download ZIP** и распакуйте архив).
3. Дважды щёлкните по скачанному `.html` — он откроется в обычном браузере (например, Chrome, Edge или Firefox).
4. Повторите действия для второго файла, чтобы сравнить реализации.

**Установка, сервер, сборка, CDN, внешние библиотеки и API-ключи не нужны.** CSS и JavaScript находятся внутри каждого HTML-файла. Следует открывать именно скачанный HTML, а не просматривать его исходный код на странице GitHub.

> Если реализация использует `localStorage`, сохранение данных при открытии через `file://` может зависеть от браузера и его настроек. Хранение данных между перезапусками — необязательное улучшение для варианта A, оно выполнено и проверялось в `tracker-v2.html`.

## Начальные данные

| Задача | Оценка | Статус |
|---|---:|---|
| Чтение | 2 ч | Готово |
| Практика | 4 ч | Активно |
| Повторение | 2 ч | Активно |

При запуске начального примера: **8 ч всего**, **2 ч выполнено**, **25% прогресса**. После отметки «Практики» готовой: **6 из 8 ч**, **75%**.

## Что проверялось

Одинаковые ручные сценарии для обеих версий:

| Тест | Проверка | Ожидаемый результат |
|---|---|---|
| **T1** | Начальный пример | 3 задачи, 8 ч всего, 2 ч выполнено, 25% |
| **T2** | Отметить «Практику» выполненной | 6 из 8 ч, 75% |
| **T3** | Выбрать фильтр «Активные» на исходных данных | В списке «Практика» и «Повторение»; прогресс остаётся 25% |
| **T4** | Пустое название, пробелы, пустые/отрицательные часы; границы 0,5–24 и шаг 0,5 | Некорректная задача не добавляется, рядом с полем видна ошибка, введённые значения сохраняются |
| **T5** | Удалить все задачи | 0 ч и 0%, нет `NaN` или `Infinity` |

По приложенному к работе отчёту, **первоначальная v1** прошла T1, T2, T3 и T5; T4 — частично (сообщение об ошибке не показывалось). **v2** отмечена как прошедшая T1–T5. Подробности представлены в [`report.md`](report.md).

```text

```

## Использование ИИ и ограничения

- **Модель:** GPT-6 в ChatGPT; обе реализации создавались с использованием одной модели.
- **Процесс:** два независимых чата; во втором документы спецификации подготовлены до генерации `tracker-v2.html`.
- **Промпты:** сохранены в `prompts.txt`.
- **Измерения:** число обращений, время и сведения о затратах (если доступны) приведены или подлежат заполнению в `report.md`.
- **Проверка:** результаты T1–T5 основаны на ручной проверке.
