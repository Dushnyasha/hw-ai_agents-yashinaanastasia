
# Proposal: Мини-трекер учебных задач

## Цель

Создать автономный мини-трекер учебных задач на неделю, позволяющий добавлять, удалять и отмечать задачи выполненными, фильтровать список и отслеживать выполнение по часам.

## Формат результата

Вариант A: один файл `tracker-v2.html`, содержащий HTML, CSS и JavaScript.

Приложение должно работать в обычном браузере без CDN, внешних библиотек, API-ключей и установки дополнительных зависимостей.

## Область реализации

- Отображение списка учебных задач.
- Добавление задачи с названием и оценкой времени.
- Удаление задачи.
- Переключение статуса выполнения.
- Фильтрация: «Все», «Активные», «Готовые».
- Отображение общих часов, выполненных часов и процента выполнения.
- Проверка корректности данных с сообщениями об ошибках.
- Адаптивное отображение на экране шириной 390 px.

## Начальные данные

| Название | Часы | Выполнено |
|---|---:|---|
| Чтение | 2 | Да |
| Практика | 4 | Нет |
| Повторение | 2 | Нет |

Начальное состояние:
- Всего: 8 ч.
- Выполнено: 2 ч.
- Прогресс: 25%.

## Не входит в обязательную область

- Серверная часть и внешние API.
- Регистрация и авторизация.
- Синхронизация между устройствами.
- Внешние библиотеки и сервисы.
- Обязательное сохранение между перезапусками.

## Необязательное улучшение

Сохранение задач в `localStorage`.

Если хранилище недоступно, приложение должно продолжать работу в памяти и показывать понятное сообщение.

При открытии через `file://` доступность и поведение `localStorage` зависят от браузера, поэтому сохранение между запусками не гарантируется.

## Критерий завершения

Обязательные требования и сценарии приёмки из спецификации выполняются. Реализация предоставлена одним автономным HTML-файлом.
